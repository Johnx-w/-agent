# 询单台：外贸邮件订单跟进前端演示

这是一个可独立运行的 React + TypeScript 原型，用模拟数据展示“客户 → 多笔订单 → 邮件沟通”的业务结构。目前只包含前端，**没有连接真实邮箱、Agent 或服务端数据库**。

## 运行

```powershell
npm install
npm run dev
```

在浏览器打开终端显示的本地地址（默认 `http://127.0.0.1:5173/`）。生产构建检查使用 `npm run build`。

## GitHub Pages

仓库推送到 `main` 后，GitHub Actions 会自动构建并发布到 <https://johnx-w.github.io/-agent/>。Vite 已配置仓库子路径 `/-agent/`，适配 GitHub Pages 项目站点。

## 可以体验的流程

- **工作台**：查看活跃客户、进行中订单、近期待办及待确认邮件。
- **总览卡片**：四张统计卡片都可以点击，分别进入客户、进行中订单、当前账号的近期待办、待人工确认。
- **切换演示账号**：点击右上角头像，在林悦、陈舟和周宁之间切换；我的待办随账号变化，选择在当前浏览器中保留。
- **客户档案**：点开 Northstar Home Inc.，可以看到已完成的首单与正在协商的复购订单。
- **订单进度**：切换看板/列表，搜索或按阶段筛选；点进订单可查看摘要、邮件证据、调整阶段、添加内部备注。
- **沟通邮件**：查看收件/已发送邮件、模拟附件、AI 提取的线索，以及订单关联。
- **待人工确认**：为归属不明确的邮件选择订单并确认。确认后，目标订单时间线会新增记录。

阶段修改、备注、人工确认结果和演示账号选择保存在当前浏览器的 `localStorage`，刷新页面后仍在。右上角问号中的“恢复演示数据”可以清空业务演示改动。该浏览器本地存储仅用于原型体验；正式版将由登录系统、后端数据库和邮件增量同步服务提供实际账号与持久化。

模拟数据位于 `src/data.ts`；页面与交互位于 `src/App.tsx`；样式位于 `src/styles.css`。
